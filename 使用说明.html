Qwen3.5-9B 本地 AI + DeepSeek Harness 侧栏开关 · 使用说明

这份文件夹是一套「开箱即用」的本地大模型方案：双击一个 bat 就能在自己电脑上跑起一个 9B 参数的中文大模型，再装一个插件，就能在 DeepSeek Harness（下称 DSH）左下角用开关启停它。

不需要显卡驱动以外的任何前置知识，也不需要 Python、CUDA Toolkit、Ollama。

使用说明.md约 15 KB同一份说明的 Markdown 源文件

1. qwen-deploy.ps1 —— 部署脚本

它按顺序做这些事，每一步失败都会用中文说明原因：

  1. 查环境：确认有 curl.exe、有 NVIDIA 驱动（nvcuda.dll）、有 MSVC 运行库（vcruntime140.dll 等，缺了会自动下载安装，会弹一次 UAC 授权）。
  2. 下载运行时：从 GitHub 拉 llama.cpp 的 Windows CUDA 版（两个压缩包共约 550 MB，解压后约 1.3 GB）。直连被墙或限速时，会自动换 ghfast.top、gh-proxy.com、ghproxy.net 等镜像重试。
  3. 下载模型：从 hf-mirror.com 拉 Qwen3.5-9B-UD-Q4_K_XL.gguf（约 5.6 GB），支持断点续传，网络中断后重跑会接着下。
  4. 启动服务：把模型整体加载到显卡上，起一个 OpenAI 兼容的 HTTP 服务（默认 127.0.0.1:8080）。
  5. 自检：发一句话给模型，把回复和「每秒多少 token」打印出来。

首次运行后，这个文件夹里会多出：

  • llama.cpp\ —— 运行时二进制、模型文件（models\）、服务日志（logs\）
  • api-info.txt —— 接口地址与调用示例（自动生成）
  • logs\ —— 启动日志

2. start-qwen.bat —— 双击就用这个

不带参数时，它等于执行 qwen-deploy.ps1 -Background -ApiTest：后台起服务，并自检一次。

带参数时，参数会原样传给脚本，例如：

start-qwen.bat -Stop          :: 停止服务，释放显存
start-qwen.bat -Status        :: 看服务状态和模型名
start-qwen.bat -Ctx 32768     :: 用更小的上下文（显存紧张时）
start-qwen.bat -Port 8081     :: 换端口（8080 被占用时）

3. api-key.txt —— 密钥

脚本启动时会读这个文件，把里面的内容当作 API 密钥。删掉它、或留空，就用默认值 sk-local-qwen。

这一份里已经预置了一串密钥，装好后 DSH 和任何客户端都填这一串（打开文件复制即可，注意别多复制空格或换行）。想换密钥，见第九节。

4. dsh-local-model-toggle-plugin-only.zip —— DSH 插件

DSH 侧栏左下角的一个胶囊开关，左键启停本地模型，右键换部署目录、设置「闲置 N 分钟自动关闭」。解压后双击 install.bat 即可安装。详细说明见第五节。

5. 部署入deepseek harness参数.docx —— 表单参数

在 DSH 里添加模型提供商时要填的字段和值。照着抄即可，本文第六节也会再写一遍。

二、这套本地 AI 是什么

项目内容
推理引擎llama.cpp（不是 Ollama，也不是 LM Studio）。同一张显卡上，llama.cpp 实测比 Ollama 快约 1.8 倍
模型Qwen3.5-9B，Unsloth 发布的 GGUF 量化版，量化级别 UD-Q4_K_XL（≈ Q4_K_M）
参数量 / 体积8.95B 参数 / 约 5.6 GB 单文件
上下文长度默认 131072（128K）。模型本身支持 262144（256K），但 12 GB 显存装不下那么长的 KV 缓存
接口形式OpenAI 兼容：http://127.0.0.1:8080/v1/chat/completions
是否需要联网装好之后完全离线可用
实测速度生成 60–75 token/秒，读入约 200–240 token/秒（RTX 5070 Ti Laptop 12 GB + 16 GB 内存）
实测显存约 10.4 GB（128K 上下文时）

它擅长什么：中文写作与改写、翻译、摘要、代码补全、简单的多轮对话。

它不擅长什么：复杂逻辑推理、长链条工具调用、超大项目代码理解。这些还是得用云端大模型。9B 参数量在本地属于「够用」档，不要指望它等于 70B。

四、第一步：部署本地 AI

预计耗时 15–40 分钟，主要取决于网速。

1. 放好文件夹

把整个文件夹放到一个路径较短、没有中文空格的位置，例如 D:\Qwen3.5。

不要放在 OneDrive / 网盘同步目录里，也不要在 U 盘上跑（模型加载会慢很多）。

2. 双击 start-qwen.bat

会弹出一个黑色窗口，标题是 Qwen3.5-9B Local API。

3. 屏幕上会发生什么

阶段你会看到大约耗时
环境检查[*] 工作目录、缺 VC++ 运行库时的 UAC 弹窗几秒
下载运行时[*] 下载 llama-b11669-bin-win-cuda-13.4-x64.zip，每涨 5% 打一行进度1–10 分钟
解压[*] 解压…30 秒
验证 CUDA[*] CUDA0: NVIDIA GeForce ... (12226 MiB)、[+] CUDA 后端可用几秒
下载模型[*] 模型 … 已下载 1234 MB / 5560 MB，每 5% 一行5–25 分钟
启动服务[+] 等待服务就绪、[+] 服务在运行10–60 秒
自检模型回复: 一段中文，生成速度: 68.3 tok/s几秒

注意：下载模型那一段，窗口可能长时间只有几行输出，这是正常的（每 5% 才打印一次）。想看实时进度可以另开一个窗口执行：

Get-Content 'D:\Qwen3.5\llama.cpp\logs\*.err.log' -Tail 8 -Wait

4. 成功的标志

看到这三行就算成了：

[+] CUDA 后端可用，模型会整体上卡
[+] 服务在运行：http://127.0.0.1:8080
生成速度: 68.3 tok/s

5. 验证一下

浏览器打开 http://127.0.0.1:8080 —— 会看到一个网页聊天界面，可以直接对话。

或者用命令行（<你的密钥> 换成 api-key.txt 里的内容）：

curl.exe -s http://127.0.0.1:8080/v1/models -H "Authorization: Bearer <你的密钥>"

返回里出现 "id": "qwen3.5-9b" 就对了。

6. 以后每次使用

双击同一个 start-qwen.bat 即可。如果服务已经在跑，它会直接提示已在运行并跳过下载。

开机自启（可选）：把 start-qwen.bat 的快捷方式放进 shell:startup 目录（Win+R 输入 shell:startup）。

7. 停止服务

start-qwen.bat -Stop

约 7 GB 显存会立刻释放。不关也行——插件可以设「闲置 10 分钟自动关闭」。

五、第二步：安装 DSH 插件

1. 解压

把 dsh-local-model-toggle-plugin-only.zip 解压到任意位置（例如桌面）。

解压后应该看到：install.bat、uninstall.bat、setup.ps1、uninstall.ps1、lib\、package.json、cordis.patch.yml、README.md、LICENSE、docs\。

2. 双击 install.bat

黑窗口会依次显示：

[0] 检查环境
[1] 找已有的模型部署目录
[2] 安装侧栏插件
[3] 写插件配置
[4] 启动模型服务
[+] 装好了。

它会自动找到第四节里那个部署目录（如果没找到，会提示你用 -DeployDir 指定；也可以直接把部署文件夹拖到 install.bat 图标上）。

看到 [i] Done 后按任意键关闭窗口。

3. 完全退出 DSH 再打开

不是关窗口，是托盘图标右键 → 退出。DSH 只在启动时加载插件。

4. 检查

重新打开 DSH，左下角（设置齿轮上方）会出现一个蓝色胶囊：

  • 左侧文字：本地 Qwen3.5-9B
  • 右侧圆钮：灰色=已停止，绿色=运行中，蓝色=启动中/停止中

5. 怎么用

操作效果
左键点一下启动 / 停止本地模型
右键点一下弹出面板：查看/更换部署目录、勾选「闲置自动关闭」并选分钟数、看最近日志
启动过程中开关上方浮出一张深色「终端卡」，逐字打出真实启动日志，服务就绪后自动消失
开关变红说明部署目录找不到了，左键会直接打开文件夹选择框

6. 卸载插件

双击 uninstall.bat，输入 Y 确认。只会摘掉插件，你的模型和 llama.cpp 文件夹不受影响。

六、第三步：让 DSH 用上这个本地模型

装好插件只是「能启停」，要让 DSH 真正把本地模型当成一个可选模型来对话，还需要添加一次提供商。

  1. 打开 DSH → 设置 → 模型（Models）
  2. 点 添加模型提供商 → 选 自定义模型 API
  3. 按下表填写（与 部署入deepseek harness参数.docx 一致）：
表单字段填什么
Provider IDlocal-qwen（随便取，能唯一识别就行）
端点http://127.0.0.1:8080/v1
协议OpenAI Chat Completions
API 密钥api-key.txt 里的那串（以 sk- 开头）
模型点「获取可用模型」→ 勾选 qwen3.5-9b
上下文窗口131072（显存小的话填 32768）
  1. 保存后完全退出 DSH 再打开。

为什么要重启：DSH 当前版本有个 bug——改完配置后热重载会报 profile reload requires the root Include entry 并把改动回滚。所有配置改动都必须靠重启生效。所以插件也建议先装好、再一次性重启。

  1. 之后在对话的模型选择里就能看到 本地 Qwen3.5-9B。切换过去即可，此时数据不再离开你的电脑。

八、常见问题

现象原因解决
双击 bat 窗口一闪就没了大概率缺 VC++ 运行库或显卡驱动右键 start-qwen.bat → 以管理员身份运行；或手动装 https://aka.ms/vs/17/release/vc_redist.x64.exe
提示「没有列出 CUDA0」驱动太旧，或这套 CUDA 构建不被驱动接受先升级 NVIDIA 驱动；仍不行就重跑 qwen-deploy.ps1 -Cuda cuda-12.4 -Force
下载卡住 / 报 curl: (35)网络被墙或证书吊销检查失败脚本会自动换镜像、并对该错误自动加 --ssl-no-revoke 重试；还不行就开代理再跑
模型下载报 429hf-mirror 限流等几分钟重跑（会断点续传）；或浏览器打开 https://hf-mirror.com/unsloth/Qwen3.5-9B-GGUF 手动下载 gguf，再 start-qwen.bat -ModelPath "文件路径"
服务起来又立刻退出显存不够，模型加载失败关掉游戏/浏览器硬件加速；或 -Ctx 32768；或把别的程序关掉腾出显存
请求返回 401密钥不对检查 DSH 里填的密钥与 api-key.txt 是否一字不差
模型回复是空的，但显示生成了几十 token模型在想事情（reasoning），max_tokens 太小就会只剩思考内容把 max_tokens 调大，或在请求里加 "chat_template_kwargs": {"enable_thinking": false}
DSH 里看不到开关没重启 DSH；或插件没装进 profile完全退出重开；仍没有就重跑 install.bat，看它是否报错
开关是红色的部署目录被移动/改名了右键开关 → 选择部署目录，重新指过去
提示 profile reload requires the root Include entryDSH 已知 bug忽略，完全退出 DSH 再打开即可
中文在 PowerShell 里显示成乱码编码问题不用管，不影响运行；不要用记事本「另存为」改 .ps1，会破坏 BOM 导致语法错误

九、安全与改密钥

  • api-key.txt 里是明文密钥，只用于本机。服务默认只监听 127.0.0.1，局域网内其他设备访问不到。
  • 不要把 -Listen 改成 0.0.0.0，除非你明确知道自己在做什么（那会把服务暴露到局域网）。
  • 换密钥的方法：
  1. 用记事本打开 api-key.txt，改成新的字符串（建议 sk- 开头 + 32 位随机字符），保存时选 UTF-8。
  2. start-qwen.bat -Stop
  3. 双击 start-qwen.bat 重新启动
  4. 把 DSH 里那个提供商的 API 密钥同步改成新的，重启 DSH。
  • 这份文件夹是连着密钥一起发出去的。收到的人应当先把 api-key.txt 改成自己的，再启动。
